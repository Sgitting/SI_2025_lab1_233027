git add SI2025Lab1Main.java - Додавање на проментие во фајлот SI2025Lab1Main.java на stage областа.
git commit -m "Remove task function implemented" - Додавање на нов комит со сите пормени кој се во staging областа на тековната гранка со соодветна порака. 
git push -u origin 1-remove-a-task-by-name - Ги додава промените од локалниот репозиториум на одалечениот репозиториум за соодветната гранка. -u се користи за локалната гранка да следи (track) оддалечената гранка.
